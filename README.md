
# To-Do App

A simple yet elegant Flask-based To-Do application with user authentication and a beautiful dark theme.

## Features

- 🔐 **User Authentication** - Register and login with secure sessions
- 📝 **Task Management** - Create, toggle status, and delete tasks
- 🌙 **Dark Theme** - Modern dark UI with cyan accents
- 👤 **User-Specific Tasks** - Each user has their own task list
- ✨ **Responsive Design** - Works on desktop and tablet

## Technologies Used

- **Backend:** Flask, SQLAlchemy, SQLite
- **Frontend:** HTML, CSS, Jinja2
- **Database:** SQLite
